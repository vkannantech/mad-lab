# MAD Lab — Mobile Application Development

10 Android lab exercises in one ready-to-run Gradle project.

➡️ **Everything is in [`Android Studio Projects/`](Android%20Studio%20Projects/) — see its [README](Android%20Studio%20Projects/README.md).**

```bash
git clone https://github.com/vkannantech/mad-lab.git
```
Then in Android Studio: **File → Open → `mad-lab/Android Studio Projects`** → wait for Gradle Sync → pick `exno1`…`exno10` → ▶ Run.
